Launcher de jogos feito em Python + CustomTkinter.
 
 - Instalação automática
 - Instalação feita por recursos externos
 - Linux no google drive e Windows no Releases / Alterações futuras para todos ficarem no releases.
 - Suporte a ZIP
 - Sistema de score
 - Navegador interno (Quebrado)
 - executáveis quebrados - Não é possível cria-los de novo no momento.
